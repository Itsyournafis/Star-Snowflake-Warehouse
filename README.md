# Star vs Snowflake Schema
### A Comparative Study Using Supermarket Sales Data Warehouse

##  Project Overview

This project demonstrates and compares two Data Warehouse schemas: Star Schema and Snowflake Schema.

We use a Supermarket Sales Data Warehouse as our practical example to understand database design, normalization, relationships, SQL queries, and analytical performance.

## Project Objectives

- Understand Star Schema architecture.
- Understand Snowflake Schema architecture.
- Implement both schemas using MySQL.
- Perform sales analysis using SQL.
- Compare query complexity and performance.
- Develop a web-based analytical dashboard.
